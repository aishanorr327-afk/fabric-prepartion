# Textile Engineering Learning App

A subject-wise educational web application for Textile Engineering students.

## Subjects

- Fabric Preparatory Process
- Fiber Science
- Pre-Spinning
- Artificial Intelligence
- Introduction to Textile Engineering

## Features

- Topic-wise learning
- Simple English explanations
- Step-by-step processes
- Exam preparation notes
- MCQs
- Viva questions

## Run

pip install -r requirements.txt

streamlit run app.py
